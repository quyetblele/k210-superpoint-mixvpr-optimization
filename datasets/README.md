# Datasets

Datasets and raw images are intentionally not committed to Git.

Expected external data includes 7-Scenes, Pitts30k-test, and project-specific captures used by the research scripts. Use the download/restore scripts in `scripts/` and `mixvpr/scripts/`, then update the dataset paths in the relevant config if your local layout differs.

Do not commit downloaded images, videos, database files, or extracted archives to this repository.
